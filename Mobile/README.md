# Mobile (React Native App)

Mobile client for user-facing flows (auth, shopping, chat, notifications, intranet check-in).

## Suggested stack
- React Native (Expo or bare)
- JavaScript (JSX)
- React Navigation
- Zustand + TanStack Query

## Initial structure
- `src/app`: bootstrap/navigation
- `src/features`: module screens/logic
- `src/shared`: shared ui/services/utils
