# BE (Spring Boot API)

Backend core for auth, RBAC, CMS, e-commerce, AI gateway, webhook, and integrations.

## Suggested stack
- Java 21
- Spring Boot 3.x
- Spring Security + JWT
- Spring Data JPA + PostgreSQL
- Redis (cache/session/rate-limit)
- MinIO (object storage)

## Initial structure
- `src/main/java/com/superapp`: source code
- `src/main/resources`: configuration
- `src/test`: tests
