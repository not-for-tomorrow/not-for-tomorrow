# FE (Web App)

Frontend web client (React + Vite, JSX).

## Suggested stack
- React (JSX)
- Vite
- Tailwind CSS
- TanStack Query
- Zustand

## Initial structure
- `src/app`: app bootstrap, routes, providers
- `src/features`: domain modules (auth, ecommerce, chat, cms...)
- `src/shared`: reusable ui/hooks/utils/api client
- `src/widgets`: composed screen blocks
